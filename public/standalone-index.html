🎙️📷 أذونات الميكروفون والكاميرا (عند الاتصال فقط):

يطلب التطبيق إذن الوصول إلى الميكروفون (والكاميرا اختيارياً عند تشغيل الفيديو) فقط عندما يقوم اللاعب بتشغيل المايك أو بدء مكالمة صوتية/مرئية مباشرة في غرف التحدي أو الغرفة الخاصة. يتم البث لحظياً بين المتصلين دون تسجيل أو تخزين أي صوت أو فيديو على أي خادم، ويمكنك إغلاق الكاميرا أو كتم المايك في أي وقت.

✅ انعدام أذونات الموقع والملفات: تم إلغاء أذونات الموقع الجغرافي نهائياً (ACCESS_FINE_LOCATION و ACCESS_COARSE_LOCATION)، ولا يطلب التطبيق الوصول إلى جهات الاتصال أو الملفات الشخصية.

📢 سياسة الإعلانات والشبكات الإعلانية المعتمدة (Ad Networks Policy):

يحتوي التطبيق على إعلانات رقمية مدعومة عبر منصات معتمدة متوافقة مع متجر Google Play (مثل Google AdMob وشبكة AppCreator24 المعتمدة). قد تستخدم هذه الشبكات معرف الإعلانات المجهول (AAID) لتقديم إعلانات ملائمة مع التزام كامل بعدم جمع أو مشاركة أي بيانات شخصية أو حساسة للمستخدمين، وتوافق تام مع برامج العائلة.

• الأصوات: يتم تخليق الأصوات محلياً عبر تقنية Web Audio API دون الحاجة للاتصال بخوادم وسائط خارجية.

• حماية الأطفال والعائلة: المحتوى الثقافي آمن 100% ومناسب لجميع الفئات العمرية.
